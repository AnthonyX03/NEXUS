THE IDEA

About NEXUS

Un punto de conexión

NEXUS es la plataforma común para los proyectos web de AnthonyX003. No es un único juego: es una colección de mundos, prototipos y experimentos que pueden evolucionar con independencia.

La idea es publicar, probar y mejorar. Un proyecto puede ser una demo, una preview temprana o un juego en desarrollo activo sin tener que esperar a estar terminado para poder jugarlo.

Filosofía de desarrollo

  • Prototype first: convertir ideas en sistemas jugables cuanto antes.
  • Play early: probar las mecánicas antes de cerrar el diseño.
  • Iterate: cambiar interfaces, sistemas y contenido según evoluciona cada proyecto.
  • Independent worlds: cada juego mantiene su propia identidad, código y evolución.

Tecnología

El ecosistema está planteado alrededor de tecnologías web: HTML, CSS y JavaScript, con interfaces adaptables a escritorio y móvil. GitHub Pages sirve como distribución web y cada proyecto puede funcionar como una experiencia independiente.

NEXUS añade además una capa PWA para que el propio portal pueda instalarse como aplicación en dispositivos compatibles.

Evolución independiente

Wasteland concentra actualmente el desarrollo principal. Royal Casino Palace funciona como demo roguelike, mientras que Night City y Tamriel son previews que pueden cambiar considerablemente.

El estado mostrado aquí pretende ser claro: lo que ves hoy no necesariamente representa la versión final de ninguno de estos mundos.

PWA / INSTALLATION

Instala NEXUS como una app

En Android y navegadores compatibles, NEXUS puede instalarse desde el propio navegador. Una vez instalado aparecerá como una aplicación independiente y se abrirá en modo standalone.

También puedes instalar cada juego

NEXUS es el portal. Cada juego mantiene su propia página y, si su implementación incluye PWA, puede instalarse por separado desde su propia URL.

En iPhone/iPad, utiliza Compartir → Añadir a pantalla de inicio cuando Safari ofrezca esta opción.

About

NEXUS reúne los juegos web de AnthonyX003 en una experiencia de acceso común. Su propósito es servir como launcher, escaparate y punto de entrada a proyectos que están en diferentes fases de desarrollo.

La plataforma está pensada para funcionar en PC y dispositivos móviles, y esta versión incorpora capacidades PWA para instalar el portal como una aplicación independiente.
